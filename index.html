Settings

Booru gallery

Only this many items are loaded on each page of the Booru Gallery. Lower numbers use less memory and keep large folders smooth (1–500).

Page width

“Stay as it is” keeps the centred, fixed-width layout. “Stretch” uses the whole browser window, which suits wide screens such as 3440 × 1440.

Admin mode

Lets this page rename and delete linked files, and add files to a manga folder, using the File System Access API. It needs Chrome or Edge (Firefox doesn’t support the API) and a folder opened with “Admin: open folder”.

Saved folder path

Firefox can’t keep folder access between visits, but it can remember where your folder is. Enter the location of the folder you pick under “Link manga folder” (for example D:\Manga or /home/me/Manga). When this page is opened as a local file, linked pages then load by themselves. Leave it blank if this HTML file sits next to that folder.

Presaved tags

One-click buttons that add a tag, language, character and so on to a folder. They appear on the folder page next to Tags.

Keybinds

Click “+ Add key”, then press the key (or combination) you want. A key can only do one thing on a screen; assigning it moves it from the other action. Presaved tags can be given keys here too.

Presaved tags

The order here is the “#” number shown in Settings. Pressing one adds it to the open folder; Language, Type, Artist, Group and Series are replaced, Tags and Characters are added to.
